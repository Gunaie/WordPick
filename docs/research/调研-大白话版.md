# 英语学习工具 · 调研（大白话版）

> 一句话说清楚我要做什么：一个能帮我真正记住单词的APP，手机电脑都能用，数据不丢，我能自己加内容，还能记笔记、整理错题。

---

## 一、市面主流工具长啥样（核心是学不背单词的好设计）

### 1. 不背单词（我要借鉴的标杆）

| 它有的东西 | 具体是什么 | 我怎么抄 |
|---|---|---|
| **原声例句** | 150万+条，都是英美剧/纪录片里摘的，带声音 | 搞点免费语料（TED、开放字幕库），或者先精简点上 |
| **词根词缀** | 2000+词根词缀，比如"pre-"="在前"，"dict"="说"→ predict（预言） | 这是真·速记神器，必须有。先整理100个常用的 |
| **派生树** | 把同根单词串成树，比如 dict → predict, dictionary, contradict | 做个树形图，点一个词能看到全家桶 |
| **考义加粗** | 四六级/考研考的意思用粗体标出来 | 按"出现频率"标颜色，红的是高频考点 |
| **考频显示** | 告诉你这个词在考试里出现过几次 | 每个词旁边加个热度条 |
| **极简设计** | 界面干净，不花里胡哨 | 白底/深色，大字号，专注内容 |

### 2. 其他工具各有什么绝活

| 工具 | 绝活 | 要不要抄 |
|---|---|---|
| **墨墨背单词** | 算法最牛，"什么时候复习"算得特准 | 必抄，这个是核心算法 |
| **扇贝单词** | 词库开放，用户能上传自己的词书 | 必抄，我也想让用户自建词库 |
| **百词斩** | 图背单词，每个词配张图 | 可选，先不上，后面再说 |
| **云生词本** | Excel/CSV批量导入 | 必抄，用户想导入自己的单词表 |

### 3. 总结：我要做的差异化

市面上这些都是**纯背单词**的工具。我想做的是：
- 🎯 不止背单词，还要**背句子**（从真题里摘的）
- 📝 有**错题本**和**笔记**功能
- 🔄 **跨端同步**（手机刷题、电脑记笔记）
- 🆙 **可迭代**（先做MVP好用，后面慢慢加功能）

## 二、核心功能清单（按优先级排）

### 先明确：四六级 / 考研英语 到底怎么支持

| 需求 | 具体做什么 | 为什么用户需要 |
|---|---|---|
| 官方考纲词表 | 导入教育部发布的 CET-4(4500词) / CET-6(6000词) / 考研(5500词) 大纲 | 考纲是硬标准，不会遗漏 |
| 考频 + 题型分布 | 每个词标"阅读高频"/"写作高频"/"听力高频"/"翻译高频" | 写作需要"会写"，阅读需要"认识"，优先级不一样 |
| 真题例句（标注年份） | "cet4-2023-12-sectionB-第3句" 这种精确来源 | 用户会想"我背的这个词真的考过吗？哪年的题？" |
| 长难句拆解（考研/六级） | 把一句5行长句拆成：主句 / 定语从句 / 同位语从句 / 关键词提取 | 考研最大痛点：每个词都认识，放一起就不懂 |
| 听力高频词（CET） | 专门标"听力高频"，多给听力例句 | CET-4/6 听力占35%，阅读高频≠听力高频 |
| 考前冲刺模式 | "距六级还有30天" → 自动分配每日任务（高频词+真题例句） | 备考是阶段性的，不是天天一样的节奏 |

### 拼写功能具体怎么做

| 模式 | 怎么玩 | 适用场景 |
|---|---|---|
| 听音拼写 | 放英音/美音 → 键盘敲字母 → 对/错判定 | 上班路上摸鱼练拼写；写作类考试 |
| 看义拼写 | 给中文释义 → 写英文 → 对/错判定 | 写作/翻译类考试主动回忆 |
| 拼写纠错练习 | 系统出带typo的词（accomodate → accommodate）→ 让用户找出错在哪 | 易混词强化 |
| 提示分级 | 不会时可点：首字母提示 → 音节数提示 → 词根提示 | 不卡死，给台阶 |

### P0 · 第一版必须有（没有就没法用）

1. **单词卡片**：单词 + 英美双发音 + 中文释义 + 例句（标注考纲归属：CET-4 / CET-6 / 考研）
2. **记忆算法**：SM-2算法（Anki同款，验证过的，简单好用）
3. **基础词库**：CET4考纲4500词 + CET6考纲6000词 + 考研考纲5500词（先高频子集，后续全量）
4. **跨端同步**：手机电脑同一个账号，数据云端存
5. **自建词库**：能粘贴或导入CSV/Excel上传自己的单词表
6. **英美发音**：同一个按钮能切换英音/美音
7. **听音拼写**：放音→敲字母→判定，typo容错（比如少一个字母也算半对）

### P1 · 第二版要加（加了就好用）

8. **词根词缀**：点击单词能看到它的"偏旁部首"
9. **真题例句**：四六级/考研真题里的原句 + 精确出处（年份/section）
10. **易混易错**：affect/effect、adapt/adopt 这种长得像的词放一起对比，带拼写纠错练习
11. **错题本**：把不会的句子/单词单独收藏（自动收集反复遗忘的词）
12. **笔记功能**：能在单词上写自己的理解，支持 Markdown
13. **看义拼写**：给中文释义写英文，带首字母提示
14. **标签系统**：用户自己给单词打标签（"写作高频"、"dict词根家族"、"考前必背"）

### P2 · 第三版再加（加了就好用到飞起）

15. **派生树**：一个词根拉全家桶
16. **考频 + 题型标注**：红/黄/绿三色 + 阅读/写作/听力/翻译分题型高频标识
17. **长难句拆解**：考研/六级真题长句 → 拆解主句/从句/语法结构 → 点词看释义
18. **基础发音教学**：IPA 音标 + 连读/重读规则 + 跟读打分
19. **句子上传**：粘贴一整段英语 → 自动提取生词 + 自动识别长难句 → 一键加入词库
20. **学习统计**：日历热力图 + 累计词汇量 + 连续天数 + "dict词根家族你还剩3个词"
21. **听写模式**：CET听力高频词 → 放音频 → 听写整句
22. **考前冲刺模式**：选目标考试 + 倒计时天数 → 自动分配每日计划
23. **自建词库发音合成**：自建词库的单词没有原生发音时，用系统 TTS 兜底

### P3 · 我认为遗漏但值得加的

24. **遗忘预警**：系统主动告诉你"这5个词你快忘了，今天必须复习"（不是被动等你点开）
25. **每日推送 / 学习日记**：每天系统推1个真题长难句 + 让你写一句话总结
26. **词根词缀主动回忆练习**：给你词根"dict" → 让你写出"predict"、"dictionary"、"contradict"
27. **数据导出**：一键导出全部单词+笔记到 Notion/Excel/Markdown（换工具也不怕丢）
28. **学习路径**：回答"我想3个月过六级"→ 系统自动算每天要背多少新词、复习多少旧词
29. **写作高频词包**：专为写作准备的高级替换词（important → crucial / vital / significant）

## 三、技术方案（大白话版）

### 用什么做？Flutter

为什么选Flutter而不是React Native？
- Flutter**一套代码**同时出手机APP（安卓+iOS）、电脑桌面APP（Win+Mac）、甚至网页
- 界面**长得一模一样**，不会出现"安卓好看iOS丑"的问题
- 性能**比RN好**，特别是动画和滚动的时候

### 数据存哪？云+本地

```
用户手机/电脑  ←→  云端数据库  ←→  用户手机/电脑
   (本地缓存)      (主存储)        (本地缓存)
```

- **云端**：用 Supabase（免费额度够个人用）或者 Firebase
- **本地**：SQLite（离线也能背单词，联网自动同步）
- **用户数据**：账号、背了哪些词、笔记、自建词库 → 云端
- **静态数据**：单词库、词根词缀 → 打包在APP里（不用每次打开都下载）

### 发音从哪来？

| 方案 | 要钱吗 | 好用吗 | 备注 |
|---|---|---|---|
| Free Dictionary API | 免费 | 有音标、有英美音音频 | 无API Key，直接用 |
| Forvo | 免费/付费 | 真人发音，英美音齐全 | 需申请API Key |
| 有道dictvoice接口 | 免费 | type=0美音，type=1英音 | 爬有道的接口，可能变 |

**推荐**：先用 Free Dictionary API + 有道的接口混合着用，哪个好用哪个。

### 词典解释从哪来？

| 方案 | 要钱吗 | 内容质量 |
|---|---|---|
| Free Dictionary API | 免费 | 够用，基础释义+例句 |
| 柯林斯API | 付费 | 最好，但贵 |
| 剑桥API | 付费 | 好 |

**推荐**：第一版用 Free Dictionary API，后续有钱了再上柯林斯。

## 四、记忆算法简单讲

**核心逻辑**：背过的词，不是"记住了"就是"忘了"，而是有个**记忆强度**。每次你正确回忆，复习时间就往后推；忘得快的词，就多复习。

**SM-2算法（先上这个）**：
- Anki用了十几年的算法，无数人验证过
- 给每个单词算一个"下次什么时候该复习"的时间
- 4个选项：简单 ✓ / 一般 ✓ / 难 ✗ / 重来 ✗✗
- 简单→间隔变7天，一般→3天，难→1天，重来→10分钟

**FSRS算法（后续升级）**：
- 2023年出的新算法，更精准
- 考虑更多因素（上次复习时间、连续答对次数等）
- 但实现复杂一点点

## 六、风险和坑

| 风险 | 怎么办 |
|---|---|
| 词典API不稳定 | 多备几个源，挂了换另一个；关键数据缓存本地 |
| 发音音频加载慢 | 第一次背的时候预下载，缓存本地 |
| 个人项目精力不够 | 功能砍到最简，先出MVP，能跑起来最重要 |
| 跨端同步冲突 | 简单做，以云端为准，本地存个版本号 |
| 词典内容版权 | Free Dictionary API用的是开源数据（Wiktionary），没问题；商业词典别碰 |

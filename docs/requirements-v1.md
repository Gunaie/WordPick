# 需求与界面方案 v1

> 状态：M1–M5 已实现（2026-11-20）
> 范围：个人自用的 Android 英语学习 App，界面参考「不背单词」，只使用自定义词书。
> 本文确认后，才进入代码改造；在此之前 `docs/architecture.md` 描述的仍是当前实现。

---

## 1. 背景与目标

### 1.1 背景

- 日常使用「不背单词」学习英语，认可其简洁、柔和、沉浸的界面。
- 其自定义词单、笔记、词根词缀、例句等能力需要付费。
- 希望为自己做一个免费、可长期使用、数据在自己手里的替代品。

### 1.2 目标

1. **只服务一个人**：不做账号体系，不做多人协作。
2. **只有自定义词书**：不内置四六级 / 考研词表，不提供别人的词书。
3. **手机优先**：Android 为主要交付形态；Web 只用于开发预览。
4. **界面安静**：全屏背景 + 大字号 + 少入口，接近参考截图的观感。
5. **离线可用**：词书、释义、学习记录、笔记都在本地；发音尽量缓存。

### 1.3 非目标

- 不做内置词库、考纲筛选、单词本覆盖度。
- 不做考试练习、真题例句。
- 不做收藏、错题本。
- 不做账号、好友、排行榜、打卡社交。
- 不做公开分发（词表与发音的授权问题不在本期处理）。

## 2. 核心使用流程

```
首次打开
└── 空状态：创建第一本词书
    └── 添加单词（输入即查释义）或粘贴导入
        └── 今日：开始学习
            ├── 有到期复习 → 先复习
            └── 没有到期 → 学新词
                └── 学习卡：四选一 → 看答案 → 自动评分 → 下一词
                    └── 结束页：本次正确率 / 连续天数
```

日常路径只有一条：**打开 → 看今日数字 → 开始学习 → 学完退出**。
词书管理、笔记、统计、设置都是低频率的二级操作。

## 4. 页面规格

### 4.1 今日

**布局（自上而下）**

1. 背景：全屏柔和渐变，占满 SafeArea。
2. 顶部：左侧小字「英语学习」，右侧设置图标（半透明白）。
3. 签到卡（居中偏上）：
   - 磨砂玻璃卡片，圆角 24，图标 + 「签到」+ 日期（如 `11/20 周五`）。
   - 副文案：`连续 7 天` / 今日未学习时显示 `今天还没开始`。
   - 点击进入学习统计。
4. 两个数字块（底部）：
   - 左：`待复习` + 数字（强调橙）。
   - 右：`今日已学` + 数字（墨绿）。
   - 数字 32–36sp，标签 13sp；点击数字块直接开始对应任务。
5. 主按钮：「开始学习」；有待复习时文案为「开始复习」。
6. 次级入口：「拼写练习」文字按钮。

**空状态**：没有任何词书时，隐藏数字块，显示「创建第一本词书」按钮和一句引导。

**规则**

- 待复习 = 所有词书中 `due <= now` 的词数。
- 今日已学 = 今日学习记录中去重后的词数。
- 签到不单独存储，由每日学习记录派生；当天学习 ≥ 1 个词即视为签到。

### 4.2 学习页（核心）

**视觉**

- 全屏渐变（每次进入可在预设渐变中轮换），无底部导航。
- 顶栏：关闭、`3/10` 进度、更多（暂时只有「跳过」）。
- 单词：36–40sp，粗体，深色。
- 音标：小字，前缀「英」或「美」，旁边一个发音按钮。
- 提示语：`先回想词义再选择，想不起来看答案`。

**四选一卡片**

- 4 张浅色卡片，圆角 18，每张：词性（如 `n.`）+ 中文释义。
- 正确项与其他 3 项来自同一词书内其他词的首条释义；词性尽量一致。
- 点击后立即判定：
  - 正确：该卡高亮墨绿，其余变淡。
  - 错误：所选卡高亮暖红，正确卡高亮墨绿。
- 判定后显示：完整释义、发音、`下一词`。笔记不放在学习卡内，作为独立模块。

**自动评分（映射 SM-2）**

| 情况 | 评分 |
|---|---|
| 答错 | 重来（重置间隔） |
| 答对 | 一般 |
| 答对且该词 `reps >= 3` | 简单 |

不额外增加自评步骤，保证每张卡一次点击加一次「下一词」。

**降级规则**

- 词书内不足 4 个「有释义」的词时，本次学习改用自评四档：重来 / 难 / 一般 / 简单。
- 词条没有释义时，先提示「补全释义后才能生成选项」，并提供快捷编辑。

**结束页**

- 本次学习 N 词、正确率、连续天数。
- 按钮：`返回今日`、`再来一组`（还有到期词时显示）。

### 4.3 词单

**词书列表**

- 每项：词书名、`已学 / 总数`、右侧箭头。
- 底部或右上角「新建词书」；长按 / 更多菜单重命名、删除。
- 空状态：一句引导 + 「新建词书」。

**词书详情**

- 顶部：词书名、总数、已学数；更多菜单：重命名、删除整本。
- 操作按钮：`添加单词`、`粘贴导入`。
- 搜索框：按单词或释义过滤。
- 列表项：单词（粗体）+ 释义（最多两行）+ 次行 `添加于 11/20 · 添加 3 次`。
- 每项右侧菜单：编辑、删除；删除需二次确认。

**添加单词**

- 输入单词 → 自动查离线词典，回填音标与首条释义（可编辑）。
- 词典查不到时，释义为空并提示「未收录，请手动填写」。
- 释义为**动态多行**：每行「词性 + 中文释义 + 英文释义（选填）」，可增删行，首行为主释义。
- 单词已存在：提示「已在词书中，是否累加次数」，确认后 `add_count + 1`。

**粘贴导入**

- 一行一个词，词性与多释义可选，例如：
  `apple n. 苹果; n. 苹果公司`
  `abandon [əˈbændən] v. 放弃; 放任`
- 语法：`单词 [音标] 词性. 释义[; 词性. 释义…]`；分号 `;` / `；` 分隔多条释义，词性写在释义前；词头的词性会自动沿用到未单独标注的释义。
- 非法行忽略并汇总提示；重复词累加次数；内置词排除逻辑随内置词库一起删除。

### 4.4 拼写练习

- 沿用现有单一模式：发音 + 释义同时展示，用户拼写。
- 递进提示：首字母 → 音节数 → 词根拆解 → **四选一**。
- 四选一给出「正确拼写 + 3 个干扰项」，优先同首字母、其次长度接近；选错划掉该选项，选对自动填充并判题；词池不足 4 个不同拼写时提示无法生成。
- 题源改为自建词；词书为空时引导去添加。
- 视觉与学习页统一：渐变背景、大字号、无底栏。

### 4.5 笔记汇总（时间线小记）

- 形态参考「小记」：每条包含标题、正文、标签、时间，可按日期分组浏览，按更新时间倒序。
- 单词作为**可选关联**（卡片上显示为 chip），不再按单词聚合。
- 标签可横向筛选，搜索同时匹配标题、正文、标签与关联单词。
- 支持新建、编辑、删除（软删除，保持同步语义）。
- 学习页不提供记笔记入口，笔记是独立模块。

### 4.6 词根词缀

- 用现有 `affixes.json` 对自建词做前缀 / 后缀 / 词根匹配。
- 无匹配时显示空状态，不虚构结果。

### 4.7 学习统计

- 近 14 天柱状图（新学 / 复习）。
- 连续天数、累计已学词数、今日学习数。
- 签到卡点击后进入本页。

### 4.8 设置

| 分组 | 项 |
|---|---|
| 学习 | 默认发音口音（英 / 美）、每组新词数（默认 10）、每组复习数（默认 20）、拼写题量（默认 10），均本地持久化 |
| 同步 | 状态、启动 / 回前台自动同步、立即同步、说明「仅本人使用」 |
| 数据 | 从 JSON 恢复、导出 JSON、导出笔记 Markdown、清空本地与云端 |
| 关于 | 版本、词书数量、总词数 |

## 5. 视觉规范

### 5.1 颜色

| 用途 | 值 |
|---|---|
| 背景渐变（晨雾） | `#FBF7F1 → #EFE6D8` |
| 背景渐变（苔绿） | `#EDF3EE → #D8E7DE` |
| 背景渐变（雾蓝） | `#EBF1F6 → #DCE8F1` |
| 背景渐变（暮粉） | `#FBF1EE → #F0DFDA` |
| 主文字 | `#2B2825` |
| 次文字 | `#6F6A63` |
| 弱文字 | `#9A948C` |
| 主色（按钮 / 正确） | `#2F6F63` |
| 强调（数字 / 下划线） | `#C4763F` |
| 错误 | `#B4544A` |
| 磨砂卡片 | 白色 62% + 背景模糊 18 |

### 5.2 字体

- 中文与正文使用系统字体，不额外打包中文字体。
- 单词使用系统 sans 粗体；数字使用等宽数字特性，避免跳动。
- 字阶：单词 38 / 首页数字 34 / 页面标题 20 / 正文 15 / 辅助 13。

### 5.3 形状与间距

- 卡片圆角 24；选项与输入框 18；按钮胶囊形或 18。
- 页边距 22；区块间距 24；列表行间距 12。
- 不使用阴影、分割线；靠留白和色差分组。
- 动效 180–220ms，淡入 + 轻微上移；不做复杂转场。

## 6. 数据与存储

### 6.1 保留的数据结构

| 结构 | 用途 | 变化 |
|---|---|---|
| `CustomWordBook` / `CustomWordEntry` | 词书与词条 | 不变 |
| `ReviewState` | SM-2 状态 | 不变 |
| `NoteRecord` | 时间线小记 | 新增 `title`、`tags`；`wordKey` 为可选关联，可为空 |
| `DailyStat` | 每日学习计数 | 不变，签到由它派生 |

### 6.2 移除的内容

- `assets/data/words.json` 及 `WordRepository` 的加载逻辑。
- 考纲筛选 `examTag`、内置词池拼接、覆盖度统计。
- `QuizPage`、`ExamSentencePage` 及其入口。
- `Word.quiz` 等只服务内置词的字段（如无其他引用可一并删除）。

### 6.3 新增：离线词典

| 项 | 方案 |
|---|---|
| 数据源 | qwerty-learner 整理的 Oxford5000 / CET-4 / CET-6 / 考研 / TOEFL / IELTS / GRE 七本词书（词条源自 ECDICT 等公开词库，MIT；个人自用，分发前需核验） |
| 裁剪 | 七本词书去重，只保留单词、音标、中文释义；过滤纯符号词与无中文释义条目 |
| 实际体积 | 13,958 词，`dict_core.json` 约 1.0 MB |
| 形式 | `assets/data/dict_core.json`（`{"word":["音标","释义"]}`）：启动加载为 `Map<String, DictEntry>`，按小写查词 |
| 查不到 | 返回空，表单提示「未收录，请手动填写」；不做在线兜底 |

### 6.4 发音

1. 播放有道 dictvoice（沿用 `AudioService`）。
2. 首次播放成功后把 mp3 缓存到应用缓存目录，以 `word_type.mp3` 命名。
3. 缓存命中直接播放；未命中且网络失败时，用设备 TTS 朗读。
4. 设置页提供「清理发音缓存」。

### 6.5 同步

- 保持单人模式：`SyncConfig.userId` 固定，界面文案写明「仅本人同步」。
- 同步时机：启动后后台同步一次；应用回到前台（含浏览器标签页恢复可见）时静默同步，60 秒内不重复；手动「立即同步」不受冷却限制。
- 同步内容：`review_state`、`note`、`user_meta.custom_books`。
- 删除词条时本地清除对应 `ReviewState`；云端残留不影响使用（词池只来自本地词书）。
- 设置（口音、每组新词数、拼写题量）只存本地 `user_meta.settings`，不参与云同步，避免多设备互相覆盖。
- CloudBase 免费额度到期前，用导出功能兜底；M7 起可在设置页从 JSON 合并恢复。

### 6.6 迁移

- 升级后首次启动：词书、笔记、复习状态原样保留。
- 内置词的复习状态成为孤儿数据：不删除、不展示，避免误删历史。
- 旧版扁平自建词继续迁移到「我的单词本」（现有逻辑保留）。

## 7. 里程碑与验收

### M1 · 数据与结构精简 ✅

- 删除内置词库加载、考试练习、真题例句、考纲筛选。
- 复习池只来自自建词书。
- 验收：无词书时首页为空状态；添加 5 个词后能进入学习；`flutter analyze` / `flutter test` 通过。

### M2 · 今日 + 学习页 ✅

- 全屏渐变首页、签到卡、两个数字块、三 Tab 半透明底栏。
- 四选一学习卡 + 自动评分 + 降级自评。
- 验收：10 词一轮可完整走完；答错词按 SM-2 重置；结束页数据正确。
- 备注：三 Tab 中的「词单」「我的」先复用现有能力，视觉细化留给 M3 / M4。

### M3A · 词单 ✅

- 词书列表 / 详情 / 加词（单词 + 音标 + 释义）/ 粘贴导入 / 编辑 / 删除。
- 搜索同时匹配单词、音标与释义；删除词条二次确认；空状态带引导按钮。
- 验收：新词书 3 步内完成建书 + 加词；重复词累加次数；音标可留空。

### M3B · 离线词典 ✅

- 新增 `assets/data/dict_core.json`（13,958 词）与 `DictionaryRepository`，随启动加载。
- 加词 / 编辑表单输入单词 300ms 后查词，自动回填空着的音标与释义；已填内容不覆盖。
- 词典查不到时提示「未收录，请手动填写」。
- 验收：常见词可带出音标与释义；生僻词可手填保存；`flutter analyze` / `flutter test` 通过。

### M4 · 笔记 / 签到 / 统计 / 词缀 ✅

- 笔记为独立模块：可随手记，也可关联单词；支持搜索、编辑、删除（软删除）。
- 备注：当时的「按单词聚合」在 M6 调整为「时间线小记 + 标签」。
- 统计页与签到数据一致：连续天数、累计已学、今日已学，近 14 天柱状图区分新学与复习。
- 词缀页只展示真实匹配：可拆解自建词、搜索词缀表，无匹配时给出说明而不虚构结果。
- 设置页 / 我的页入口列表视觉统一，新增「立即同步」与关于信息。
- 验收：笔记跨端同步后可读；连续天数计算正确。
- 备注：首页签到卡点击进入统计页，与统计页数据同源（`DailyStat` 派生）。

### M5 · 发音与收尾 ✅

- 发音缓存：有 mp3 落应用缓存目录 `pronunciation/word_type.mp3`，命中直接播本地；首次播放先下载再播。
- 网络失败时用设备 TTS 朗读（`flutter_tts`，英 / 美对应 en-GB / en-US）；Web 端由浏览器管理缓存。
- 设置页新增「发音」分组：显示缓存占用、清理缓存。
- 导出：JSON（词书 / 笔记 / 复习进度 / 每日统计）与笔记 Markdown（按单词分组）。
  Web 触发浏览器下载，原生写入临时文件后调起系统分享。
- 验收：断网时已缓存词可发音；导出文件可被重新导入或阅读。
- 备注：默认发音口音与每组新词数当时未暴露，已在 M7 补齐并持久化。

### M6 · 时间线小记 + 多释义词条 ✅

- 笔记改为时间线小记：标题 / 正文 / 标签 / 可选关联单词，按日期分组倒序，支持标签筛选与全文搜索。
- 笔记数据新增 `title` / `tags`：SQLite 旧库自动 `ALTER TABLE` 补列，Web 旧 JSON 缺字段安全降级；云同步 `note` 表需手工补列（见 `docs/cloudbase_schema.sql`）。
- 自建词支持词性与多释义：粘贴导入按分号拆分释义、识别词性前缀与音标；单个加词 / 编辑表单改为可增删的多释义行。
- 词单列表最多展示两条释义；学习卡完整展示，拼写提示最多 3 条，避免长释义撑破布局。
- 验收：`flutter analyze` 0 issue、`flutter test` 42 项通过、`flutter build web` 通过。

## 8. 风险与待定

| 风险 | 影响 | 应对 |
|---|---|---|
| 自建词释义由自己填写，质量参差 | 四选一干扰项质量下降 | 选项只取首条释义并截断；允许随时编辑 |
| 词量少时首页数字很小 | 视觉显得空 | 首页展示今日任务与连续天数，不展示总量 |
| 离线词典数据授权 | 公开分发受限 | 本期仅个人自用；分发前替换或核验授权 |
| TTS 插件增加构建复杂度 | Windows / Web 兼容性 | 仅作为失败兜底；构建问题按 ISSUE 记录处理 |
| 删除内置词库导致历史进度不可见 | 用户可能疑惑 | 保留数据不删；文档与设置页说明 |

待定：

1. 笔记导出 Markdown 仍按单词分组（随手记单独一组），是否跟随时间线改为按日期分组待定。

# 功能地图：离线能力与后续规划

> 适用版本：v0.22（M1–M15 + 发音超时熔断 + FSRS-6 默认调度） ｜ 更新日期：2026-11-21
> 本文只做现状盘点与可行性分析；第 4 节 4.1、4.2、4.4（P1 + P2）、4.5 已实现，4.3 结构性已完成。

## 0. 阅读说明

**网络状态**

| 标记 | 含义 |
|---|---|
| 离线 | 不联网可完整使用 |
| 混合 | 有网体验更好，无网有降级路径 |
| 联网 | 必须联网才有意义或才能工作 |

**难度**（相对复杂度，不是工期）

| 标记 | 含义 |
|---|---|
| S | 局部改动：单页面或单函数，通常不涉及数据结构 |
| M | 中等：涉及数据层、多页面联动或数据迁移 |
| L | 较大：跨端存储、同步、新依赖或新交互模型 |
| XL | 很大：富文本 / 媒体 / 云存储 / 导出全链路 |

## 1. 一句话结论

核心学习闭环（词书、复习、拼写、统计、笔记、设置、导出）**100% 离线可用**；
只有**云同步**和**首次发音下载**依赖网络，且两者失败都不影响本地学习。
因此后续功能应继续坚持「离线优先，联网只做增强」。

## 2. 网络依赖总览

| 能力 | 何时联网 | 无网时的表现 |
|---|---|---|
| 词书 / 自定义词条 | 不需要 | 完整可用 |
| 离线词典回填（1.4 万词） | 不需要 | 完整可用（打包资产） |
| 学习四选一、SM-2 复习 | 不需要 | 完整可用 |
| 拼写练习与四级提示 | 不需要 | 完整可用（提示全部本地计算） |
| 词根词缀 | 不需要 | 完整可用（打包资产） |
| 统计、连续打卡 | 不需要 | 完整可用 |
| 笔记、标签、搜索 | 不需要 | 完整可用 |
| JSON / Markdown 导出与恢复 | 不需要 | 原生走系统分享，Web 走浏览器下载 |
| 单词发音 | **首次播放**需下载有道音频 | 已缓存 → 离线播放；未缓存且下载失败 → 设备 TTS 兜底；Web 端只依赖浏览器 HTTP 缓存，不保证离线 |
| 云同步 | 启动、回前台、手动同步 | 失败只记录状态，本地数据不受影响 |
| Web 端打开应用 | 首次加载页面 | 页面未加载则无法使用；加载后数据在本地 |
| 安装 / 更新 APK | 传输或下载安装包 | 已安装版本可离线使用；更新需联网或手动传输 |

## 4. 后续想法逐项分析（4.1 / 4.2 已实现）

### 4.1 按音节拆词，辅助记忆 ✅ 已实现（M12）

| 项 | 结论 |
|---|---|
| 网络 | 离线 |
| 难度 | **M** |
| 建议优先级 | 高（P1） |

**实现思路**

- 在 `spelling_hints.dart` 现有 `syllableCount` 基础上新增 `splitSyllables(word) -> List<String>`，输出 `re·sil·ient`。
- 规则层：元音核切分、辅音丛归属、`-le` 结尾、常见前缀 / 后缀、词尾哑音 `e`。
- 例外层：内置一份小型「不规则音节」词典（如 `business → busi·ness`），查不到再回退规则。
- 展示层：词条详情、学习卡、拼写提示均可显示分节；不参与判题，不影响 SRS。

**风险**

- 纯规则对专有名词、复合词、不发音字母的准确率有限，错误分节会误导记忆。
- 完整音节词典体积与授权需要确认；建议先规则 + 例外表，准确率稳定后再考虑更大的数据源。
- 音节数提示已存在，需避免两处算法不一致（应共用同一套切分结果）。

**结论**：收益高、改动集中，适合在下一轮优先做。

**决策（2026-11-21）**：采用「规则 + 例外表」，不引入完整音节词典。切分不确定时**宁可不显示分节**，也不展示可能错误的结果；上线前用常见词表做回归校验，音节数与分节必须共用同一套算法。

**实际实现**：`spelling_hints.dart` 新增 `splitSyllables`，后缀优先成节，元音组作核，辅音丛按最长合法声母分配，另有约 35 词例外表；无法可靠切分（非纯字母、未知元音组合等）返回 `null`。`syllableCount` 优先取分节长度。学习卡 / 回看卡 / 拼写提示 / 词单均以 `·` 展示，null 或不足两段时隐藏。

### 4.2 背单词时返回查看上一个单词 ✅ 已实现（M11）

| 项 | 结论 |
|---|---|
| 网络 | 离线 |
| 难度 | **S** |
| 建议优先级 | 高（P1，可与 4.1 同期） |

**关键约束**

- 当前答完即写入 SM-2（`AppState.grade`），**返回后不能重新作答**，否则会重复计分、打乱间隔。
- 因此建议做成「只读回看」：保留每题快照（词、选项、作答、判定、提示级数），返回时展示原结果，提供「回到当前」按钮。

**实现思路**

- 学习页维护 `List<_RoundSnapshot>`，`_index` 只前进不回退；回看用独立 `_reviewIndex`。
- 回看状态隐藏作答按钮，顶部显示「回看 3 / 10」。
- 明确返回手势：顶部返回键用于回看，退出仍走系统返回 / 关闭按钮，需避免误退出。

**风险**：回看与「跳过」的边界要定义清楚（跳过不写状态，可回看但不显示判定）。

**决策（2026-11-21）**：只读回看，**不允许重新作答**。答完即已写入 SM-2，重答会造成重复计分和间隔失真；跳过词可以回看，但不显示判定。

**实际实现**：`learning_page.dart` 用 `Map<int, _RoundSnapshot>` 保存每回合单词、选项、所选、判定 / 自评与跳过标记；`_reviewIndex` 与 `_index` 分离，回看不改动当前题状态；顶栏「上一词」可连续向前，底部「回到当前」退出回看。

### 4.3 自定义词的多词性、多释义

| 项 | 结论 |
|---|---|
| 网络 | 离线 |
| 难度 | **已完成（M）** |
| 建议优先级 | 仅需小修（P2） |

**现状（已支持）**

- 数据结构：`Word.defs` 为 `List<WordSense>`，每条含词性、中文释义、可选英文释义。
- 单个加词 / 编辑：动态多释义行，可增删，首条为主释义。
- 批量导入：`apple n. 苹果; n. 苹果公司`，分号拆条，词性可写在每条前，词头词性会自动沿用。
- 音标：支持 `[..]` 与 `/../`；序号 `1.`、`(1)` 会被忽略。
- 展示：词单最多两条，学习卡完整展示，拼写页最多三条。

**仍可补的小项**

- 多释义的排序 / 拖拽调整。
- 导入时对「同词性 + 同释义」去重。
- 每条释义可加例句或备注（需要新增字段与同步列）。
- 四选一目前只考主释义，可考虑多选题或按释义轮换出题。

**结论**：结构性工作已完成，后续属于体验优化，不构成新功能。

### 4.4 笔记变成与单词无关的文本编辑器，并支持图片（P1 + P2 ✅ 已实现，M13）

| 项 | 结论 |
|---|---|
| 网络 | 文本离线；图片本地离线；跨设备图片需联网 |
| 难度 | 纯文本 **S/M**；本地图片 **L**；图片 + 云同步 **XL** |
| 建议优先级 | 文本解耦（P1）；本地图片（P2，不做云同步） |

**现状**

- 笔记已经是独立时间线，单词关联是**可选**字段；不填即随手记。
- 数据层 `word_key` 为 `NOT NULL`，但允许空串，因此「完全去掉关联」主要是 UI 与搜索逻辑调整，不一定需要改表。

**分阶段建议**

| 阶段 | 内容 | 难度 |
|---|---|---|
| P1 ✅ | 去掉「关联单词」输入与 chip，搜索只保留标题 / 正文 / 标签 | S |
| P2 ✅ | Markdown 编辑 + 简易工具栏 + 预览切换 | M |
| P3 | 本地图片：原生存应用目录相对路径；Web 用 IndexedDB 存 Blob | L |
| P4 | 图片云同步 | 暂不做 |

**关键取舍**

- **编辑器格式（已定）**：Markdown + 移动端简易工具栏（加粗 / 标题 / 列表 / 插图）+ 预览切换，不做富文本（Quill）。导出、同步、存储都更简单，跨端一致。
- **图片同步（已定）**：图片**只保存在产生它的设备上**，不参与云同步；其他设备显示「图片仅保存在原设备」占位，文本仍正常同步。主要使用手机，这个取舍可接受。
- **图片存储**：原生复制到应用私有目录，数据库只存相对路径；Web 用 IndexedDB，不把 base64 写进 SQLite / Postgres。localStorage 约 5MB，不能用于图片。
- **导出**：Markdown 导出先跳过图片或标注「图片未包含」；后续若需要完整备份，单独做 zip（Markdown + 图片），不塞进 JSON。
- **清理与丢失**：删除笔记时清理孤儿图片；卸载 / 清数据会丢失本地图片，需在界面写明。

**结论**：先做 P1 + P2（独立笔记 + Markdown）；P3 本地图片单独评估；P4 云图片明确不做。

**实际实现（M13）**：P1 + P2 已完成。笔记编辑改为全屏页面，工具栏含标题 / 加粗 / 斜体 / 列表 / 引用 / 行内代码，预览原位切换；`domain/markdown.dart` 做块级解析，`ui/markdown_text.dart` 负责渲染，无第三方依赖。数据层保留 `word_key` 兼容旧数据与云同步，新笔记写空串；Markdown 导出改为按更新日期分组。P3 / P4 未做。

### 4.5 易混词绑定，连续出现强化记忆 ✅ 已实现（M14）

| 项 | 结论 |
|---|---|
| 网络 | 离线；若多端共享分组则需同步 |
| 难度 | **M**（只做分组与队列插入）到 **L**（改变 SRS 语义） |
| 建议优先级 | 中（P2） |

**数据模型（建议）**

- `ConfusableGroup { id, name, wordKeys[], createdAt }`，一个词可属于多个组。
- 第一阶段可复用 `user_meta` 的 JSON 存储（与自建词书同机制），避免改表；后续再升级为独立表 + 云同步。

**调度方案对比**

| 方案 | 做法 | 优点 | 代价 |
|---|---|---|---|
| A 软绑定（推荐先做） | 某组成员到期时，把同组其他词紧接插入本轮队列，标记「关联复习」 | 符合「先后出现」的直觉，不改 SRS 公式 | 未到期词被提前复习，间隔会被重算 |
| B 硬绑定 | 整组共享一个到期时间 / 一起到期 | 行为一致、实现简单 | 失去单词粒度的难度差异 |
| C 仅对比模式 | 不改日常队列，另设「易混组」练习入口 | 零风险 | 不满足「每次记忆都出现」 |

**已定边界（2026-11-21）**

- 组大小 2–4 个词，避免一轮被一组占满。
- 组成员已在队列中时不重复插入；跳过 / 答错的词下一组按正常规则重新入队。
- 关联插入**占用**每轮上限，但不链式扩散：一组词只触发一次相邻插入，避免 A 组带出 B 组。
- 组内顺序每轮**随机**，防止记住位置而不是词义。
- 一个词可属于多个组；同一轮内按首次出现去重，不重复插入。
- 删除词条时同步清理分组引用；允许跨词书组词。

**结论**：采用方案 A（软绑定），允许提前复习未到期词并正常计分。SM-2 公式不变；提前复习会按实际作答重算该词间隔，这是可接受的代价。不做硬绑定，也不做纯对比模式。

**实际实现（M14）**

- `domain/confusable_group.dart`：`ConfusableGroup { id, name, wordKeys, createdAt }`，JSON 双向、容错去重。
- `domain/confusable_queue.dart`：`buildConfusableRound` 纯函数，把同组同伴紧接插入触发词之后；组内随机、只触发一次、不链式扩散、已在队列不重复插入；超出 `dueLimit + newLimit` 时从尾部挤占新词。
- 存储：原生 `meta.confusable_groups`、Web `es_confusable_v1`、内存 stub；云同步写入 `user_meta.confusable_groups`，按组 id 并集合并、本地优先。
- 界面：「我的 → 易混词」支持新建 / 编辑（可选组名、搜索选词 2–4 个）/ 删除；学习卡与回看卡显示「关联复习 · 组名」。
- 清理：删除词条或整本词书后自动移除分组引用，不足 2 个有效词的组丢弃。

## 6. 需要联网才成立的能力（供取舍）

以下能力与「离线优先」冲突较大，新增前需明确是否值得：

- 云同步、多设备实时一致（已可选）。
- 在线词典 / AI 例句 / AI 讲解（当前词典完全离线）。
- 首次发音下载（当前已缓存 + TTS 兜底）。
- 账号体系、跨用户共享词书。
- Web 端托管与访问（需服务器 / 静态托管）。
- 应用内检查更新（当前需手动安装 APK）。

## 7. 已决策（2026-11-21）

| 编号 | 问题 | 决策 | 理由与影响 |
|---|---|---|---|
| 1 | 笔记编辑器 | **Markdown + 简易工具栏 + 预览切换**，不做富文本 | 移动端加工具栏即可顺手输入；序列化、导出、同步、恢复都简单，跨端一致 |
